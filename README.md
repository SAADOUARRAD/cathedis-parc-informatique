# Cathedis - Parc Informatique

## Description
Plateforme intelligente de gestion du parc informatique de Cathedis.

## Technologies
- Next.js 15 (App Router)
- TypeScript
- MySQL + Prisma ORM
- Material UI
- Auth.js v5

## Installation

```bash
npm install
npx prisma db push
npx prisma db seed
npm run dev
```

## Configuration
Copiez `.env.example` en `.env` et remplissez les variables d'environnement.
